# Space Weed site

The built pages of the Space Weed site, served by GitHub Pages at https://spaceweedusa.com/. This is a build
artifact: the sources, design records and tools live in a private repository.

For adults 21 years of age and older.

Pictures and footage: the client's own photographs, and photographs of Earth and space from NASA, ESA/Webb and
ESO, credited in each page's footer. Not affiliated with or endorsed by any space agency.
