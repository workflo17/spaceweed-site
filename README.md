# Space Weed site mockup

The built pages of a proposal mockup for the Space Weed flower brand, served by GitHub Pages at
https://workflo17.github.io/spaceweed-site/. This is a build artifact: the sources, design records and tools live
in a private repository, and every file here is written by its build script.

For adults 21 years of age and older. Not the live site; some statements on it are waiting for the client's
confirmation. The pages are marked `noindex`.

Pictures and footage: the client's own photographs, and photographs of Earth and space from NASA, ESA/Webb and
ESO, credited in each page's footer. Not affiliated with or endorsed by any space agency.
